# v1.2 Voice Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add secure Mandarin voice transcription to the Today composer while preserving the existing editable text parsing and confirmation flow.

**Architecture:** A `daily-composer` component renders text, voice, and status controls; a `voiceRecorder` utility owns native recording lifecycle; and a new `speechToText` cloud function calls Tencent Cloud Sentence Recognition using environment credentials. Transcription returns editable text to the existing Today page and never writes audio or records automatically.

**Tech Stack:** Native WeChat Mini Program WXML/WXSS/JavaScript, `wx.getRecorderManager`, WeChat Cloud Functions, Tencent Cloud ASR Node.js SDK, Node test runner.
